Platroomer

Windows

Voici Platroomer ! Un platformer original où vous incarnez un jouet généré aléatoirement. Relevez des défis variés dans une chambre immense : parcours classiques, niveaux avec pouvoirs spéciaux, ou encore des parties de cache-cache géantes !

Le jeu propose également un mode multijoueur local : coopérez pour franchir les obstacles ou jouez-la perso pour gagner !
